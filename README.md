# Wabui Nelson Engineering & Architecture

A responsive static website for Wabui Nelson Engineering & Architecture.

## Files
- `index.html` — website structure/content
- `styles.css` — responsive navy/orange visual system
- `script.js` — mobile navigation
- `images/` — ready for real project photography

## Before publishing
Replace the placeholder email and phone number in `index.html` with the real contact details. Replace the three project visual placeholders with real project photos when available.

## GitHub Pages
Upload the contents of this folder to the repository root, then enable GitHub Pages from the repository's Pages settings using the main branch.
